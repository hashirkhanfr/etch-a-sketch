# Etch-a-Sketch

A fun and interactive web-based Etch-a-Sketch application. This project is a part of my web development experiments, where I explore and implement different web technologies.

## Features

- **Interactive Drawing:** Allows users to draw on the screen using mouse movements.
- **Clear Screen:** Users can easily clear the drawing area and start afresh.
- **Responsive Design:** The application is designed to be responsive and works well on different screen sizes.
- **Customizable Grid:** Users can customize the grid size for drawing.

## Technologies Used

- **JavaScript (47.4%):** Handles the interactive drawing logic and user inputs.
- **CSS (30.2%):** Styles the application, making it visually appealing and responsive.
- **HTML (22.4%):** Provides the structure of the application.

## How to Use

1. Open the application in a web browser.
2. Use the mouse to draw on the grid.
3. Click the "Clear" button to clear the drawing area.
4. Adjust the grid size using the provided controls.
